PARA PROBAR EN VS CODE
1. Descomprimir este ZIP en una carpeta nueva (no encima del original).
2. Abrir esa carpeta en Visual Studio Code.
3. Usar Live Server -> Open with Live Server en index.html,
   o abrir index.html con el navegador.
4. Presionar «Abrir invitación» para ver la página y activar la música.
